
# PORTFLOW Technologies

## Python

Used as the primary programming language for backend logic, document processing and application functionality.

## Flask

Used as the web framework responsible for application routes, API endpoints, authentication and backend integration.

## SQLite

Used as the relational database for storing system information and operational records.

Used for PDF reading, validation and information extraction.

Used to structure the web application's interface.

## CSS

Used for visual styling and interface design.

## JavaScript

Used for frontend interactions and communication with the backend APIs.

The project includes an automated test suite covering authentication and 17 acceptance test scenarios.
